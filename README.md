------------------------------------------------------------------------

## 📋 Sobre o Projeto

O **Raízes do Amanhã** é um site institucional desenvolvido com **HTML e
CSS**. O objetivo é apresentar uma organização social, divulgar seus
projetos e mostrar formas pelas quais as pessoas podem conhecer o
trabalho realizado e contribuir com a iniciativa.

A página foi organizada em seções para facilitar a navegação e reunir as
principais informações em um único lugar. O visual utiliza imagens,
textos, cards e áreas de contato, com adaptação para diferentes tamanhos
de tela.

## 🚀 Seções e Funcionalidades

### 🎨 Apresentação visual

-   Layout organizado com cabeçalho, menu de navegação e rodapé.
-   Cards para apresentar os projetos.
-   Imagens distribuídas entre a seção principal, projetos e galeria.
-   Estilos definidos em um arquivo CSS separado do HTML.
-   Classes com nomes simples e relacionados ao conteúdo de cada seção.
-   Comentários no CSS para separar os estilos por seção.

### 📱 Responsividade

O CSS inclui ajustes para telas menores, reorganizando os elementos para
que a página continue legível e utilizável em diferentes larguras de
tela, como computadores, tablets e celulares.

## ▶️ Como Executar

**1. Baixe ou clone o projeto.**

Se o projeto estiver em um repositório Git, utilize:

``` bash
git clone URL_DO_REPOSITORIO
cd raizes-do-amanha
```

Substitua `URL_DO_REPOSITORIO` pelo endereço correto do repositório.

**2. Abra o arquivo `index.html`.**

Você pode abrir o arquivo diretamente no navegador ou utilizar a
extensão **Live Server** no Visual Studio Code para visualizar a página
durante o desenvolvimento.

**3. Confira as imagens.**

Mantenha a pasta `imagens/` e os arquivos de imagem nos caminhos
utilizados pelo HTML para que sejam exibidos corretamente.

------------------------------------------------------------------------

## 📁 Organização do Código

-   **`index.html`:** contém as seções, textos, links, imagens e
    elementos da página.
-   **`style.css`:** concentra os estilos visuais e as regras de
    responsividade.
-   **`imagens/`:** armazena os arquivos de imagem utilizados no site.

A separação entre HTML e CSS facilita a leitura do código e permite
alterar a aparência da página sem misturar os estilos à estrutura do
conteúdo.

## 📌 Observações

-   O site é uma página institucional estática, desenvolvida com HTML e
    CSS.
-   Para visualizar corretamente, mantenha a estrutura de pastas e os
